Maguffin External Libraries

DirectFB

DirectFB is the base Maguffin graphics system. It is a thin library that provides hardware graphics acceleration or software emulation, input device handling, and windowing support including translucent windows. It operates on top of the Linux framebuffer device. Each hardware abstraction layer has a corresponding software fallback that is not supported by hardware. DirectFB also has an IPC implementation called fusion for rapid data sharing between processes.

Maguffin is using DirectFB for the underlying graphics primitives, toolbox support in combination with LiTE, event handling, clipboard support, the window manager, application launching, etc. In addition, the fusion module is used for between-process messaging.
